# 一篮 - P0 Acceptance

1. **22 Screen**：路由/Sheet 都能到达；L1 底栏固定 4 项，无返回箭头。
2. **再搭一篮**：可设置天数/餐次、承接上一篮、多选风格、可选细化、从“想吃的”多选锚点菜、设置做饭习惯；生成食材建议。
3. **建议量不入库**：AI 食材建议只进入采购草稿；用户完成采购并确认实际量后才增加库存。
4. **部分购买**：没买到的项目不能出现在真实库存；已买量可改。
5. **识别可纠错**：小票/食材/厨房/菜品图解析后必须能编辑；识别失败不阻断手动流程。
6. **做饭推荐**：菜卡来自真实 Recipe Library；滑动不写永久 dislike；点心才上桌。
7. **圆桌**：多菜可添加/删除；整餐需求聚合；同一库存不能被多道菜重复超额占用。
8. **换个方向**：修改当顿人数/类型/时间等只更新当前候选，保留桌上已有菜；不回写本轮偏好。
9. **教程**：多菜时生成一条整餐协同长滚动教程，考虑灶位/锅具/等待时间/少洗锅/总时长。
10. **完成做饭**：确认实际用量后库存仅扣一次；重复提交不重复扣。
11. **食记**：拍照可保存到吃过的/想吃的；保存食记本身不自动扣库存。
12. **想吃的**：可作为下一篮候选；真正批量选择发生在“再搭一篮”的 Picker。
13. **我的厨房**：可新增/修改/停用厨具；后续推荐/教程读取更新后的长期数据。
14. **视觉**：不得用 Screen/裁片实现交互 UI；生成的独立 asset 风格一致；无无功能氛围小字。
